## 📂 Featured Automations

### 1. Facebook Comments → Google Sheets → HubSpot
*Tool:* Make.com

When someone comments on a Facebook Page, this automation saves it to Google Sheets and creates a new Contact in HubSpot.

*Flow:* Facebook Pages Watch Comments → Google Sheets Add a Row → HubSpot Create a Contact

*Result:* All leads saved automatically. No missed comments. Easy follow-up.

### 2. Gmail → Google Sheets → HubSpot Deal
*Tool:* n8n

When a new email arrives in Gmail, this automation saves the details to Google Sheets and creates a new Deal in HubSpot.

*Flow:* Gmail Trigger → Google Sheets Append Row → HubSpot Create a Deal

*Result:* No missed leads from email. Sales pipeline updated in real-time.

### 3. SerpApi Scraping → Google Sheets
*Tool:* Make.com + SerpApi

Automated web scraping that collects data and saves it directly to Google Sheets.

*Flow:* SerpApi Scraper → Google Sheets Add a Row

*Result:* Fast research. Clean data. No manual scraping.
